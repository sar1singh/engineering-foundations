# ARRAYS + HASHING

## Goal

Recognize when linear scan, frequency counting, or hash map lookup solves the problem.

## Core Ideas

- Use arrays for ordered traversal
- Use hash maps for fast lookup
- Use sets for duplicate detection
- Use frequency maps for counting characters or values
