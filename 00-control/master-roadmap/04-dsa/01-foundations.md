# DSA FOUNDATIONS

## First Foundation

Topic: Big-O Complexity + Arrays/Hashing

Purpose:
- Build the habit of comparing brute force and optimized solutions
- Learn to reason about time and space before memorizing patterns
- Start with high-frequency interview basics

## Concepts

- O(1): constant-time lookup or assignment
- O(n): one pass through input
- O(n log n): sorting or divide-and-conquer style work
- O(n^2): nested comparison across input
- Space complexity: extra memory used by the solution

## Required Explanation Format

For every problem, write:
- Brute force idea
- Optimized idea
- Time complexity
- Space complexity
- One plain-English explanation

## Pass Criteria

- Easy problem solved in under 20 minutes
- Complexity explained without notes
- Can explain why hash maps reduce repeated searching
