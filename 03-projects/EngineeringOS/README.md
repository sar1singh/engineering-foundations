# EngineeringOS

EngineeringOS is a Career Transformation Operating System for Engineers.

It is not just a course app, roadmap app, notes app, dashboard app, or LeetCode clone. The product is being shaped around this loop:

```txt
Current State
  -> Target Role
  -> Capability Graph
  -> Roadmap Projection
  -> Daily Missions
  -> Topic Readiness
  -> Interview Readiness
  -> Offer Readiness
```

The first customer is the founder/user. The first success criterion is whether EngineeringOS helps the founder move from current Senior/Lead backend engineer level toward Solution Architect, Engineering Manager, Staff-level, FAANG-level readiness, and a 70-80+ LPA product/GCC outcome.

Current strategy docs live in `docs/PRODUCT_STRATEGY.md`, `docs/BETA_MVP_STRATEGY.md`, and `docs/NEXT_MVP_BUILD_SEQUENCE.md`.
