Anatomy of a B-Tree Node

Unlike binary trees, B-Trees are "fat" and shallow. This design minimizes disk I/O, which is the primary bottleneck in database operations. Every node is perfectly sized to fit into a single disk block (usually 4KB or 8KB).

c++ 
struct BTreeNode {
    bool is_leaf;
    int num_keys;
    int keys[MAX_KEYS];
    BTreeNode* children[MAX_KEYS + 1];
    
    // Node fits exactly in one 8KB page
};

Page Splitting Mechanics

When an insert operation causes a node to exceed MAX_KEYS, it undergoes a page split. The median key is pushed up to the parent, and the remaining keys are divided evenly into a new sibling node. This operation cascades upwards, potentially increasing the depth of the tree if the root splits.

lightbulb Interview Tip: Be prepared to whiteboard the page split process. Interviewers look for handling of the edge case where the root node itself needs to split.
