# EngineeringOS: Mission Control Hub ## Product Overview **The Pitch:** A premium, dark-mode command center designed to act as the "emotional shell" for software engineers leveling up their careers. It distills complex skill progression into immediate, actionable momentum. **For:** Software engineers preparing for high-tier roles who need structured motivation, clear progression tracking, and focused daily execution. **Device:** desktop **Design Direction:** High-end aerospace cockpit meets modern developer tooling. Deep space darks, frosted glass surfaces, and intense, functional neon accents for data visualization. **Inspired by:** Linear, Vercel, SpaceX Dragon UI. --- ## Screens - **Command Center:** The primary dashboard aggregating next actions, readiness metrics, and current course momentum. - **Readiness Cockpit:** Detailed breakdown of proficiency across core engineering pillars. - **Weak Area Repair:** Focused queue for revision loops and spaced repetition tasks. - **Career Assets:** Actionable checklist tracking resume, portfolio, and artifact completion. --- ## Key Flows **Daily Mission Execution:** User starts their day and executes the primary task. 1. User is on Command Center -> sees **Today's Mission** card pulsing slightly 2. User clicks **[Execute Mission]** button -> transitions to focus mode module 3. Task completes, **Readiness Cockpit** rings animate and increment **Repairing Weaknesses:** User addresses failing metrics. 1. User is on Command Center -> sees Rose-tinted **Weak Area Repair** badge 2. User clicks **[Enter Repair Queue]** -> opens Weak Area Repair screen 3. User completes flashcard/quiz -> item is removed, queue count decrements ---
Design System ## Color Palette - **Primary:** `#00E5FF` - Cyan (Coding / Primary CTAs) - **Background:** `#09090B` - Deep void black - **Surface:** `#18181B` - Elevated cards (often with 60% opacity for glassmorphism) - **Text:** `#EDEDED` - Primary text - **Muted:** `#A1A1AA` - Secondary text, borders, inactive states - **Accent - Sys Design:** `#B026FF` - Purple neon - **Accent - AWS:** `#FFB000` - Amber neon - **Accent - Interviews:** `#7C3AED` - Violet neon - **Accent - Repair:** `#F43F5E` - Rose/Red alert ## Typography Using Geist for its modern, engineered precision, paired with Geist Mono for technical data. - **Headings:** `Geist Mono`, 600, 24-32px, tracking -0.5px - **Body:** `Geist`, 400, 15px, leading 1.6 - **Small text:** `Geist`, 400, 13px, text-muted - **Data/Metrics:** `Geist Mono`, 500, 14px - **Buttons:** `Geist Mono`, 500, 14px, uppercase **Style notes:** Heavy use of `backdrop-blur-md` on surface cards over subtle radial gradients in the background. 1px `#27272A` borders on all cards. Glowing `box-shadow` on hover for interactive elements corresponding to their accent color. ## Design Tokens ```css :root { --color-primary: #00E5FF; --color-bg: #09090B; --color-surface: rgba(24, 24, 27, 0.6); --color-text: #EDEDED; --color-muted: #A1A1AA; --color-sysdesign: #B026FF; --color-aws: #FFB000; --color-interviews: #7C3AED; --color-repair: #F43F5E; --font-sans: 'Geist', sans-serif; --font-mono: 'Geist Mono', monospace; --radius-card: 12px; --radius-btn: 6px; --spacing-base: 8px; } ```

Build Guide **Stack:** HTML + Tailwind CSS v3 + (Framer Motion / GSAP for ring animations if using JS framework) **Build Order:** 1. **Command Center** - Establishes the deep dark background, glassmorphism surfaces (`bg-zinc-900/60 backdrop-blur-md`), and typography hierarchy. Sets the core SVG ring components. 2. **Readiness Cockpit** - Reuses ring components, introduces complex charts and tabbed navigation. 3. **Weak Area Repair** - Establishes the focused layout and interactive card mechanics. Uses the Rose accent heavily. 4. **Career Assets** - Builds out form elements, lists, and file dropzones using the established design tokens.
