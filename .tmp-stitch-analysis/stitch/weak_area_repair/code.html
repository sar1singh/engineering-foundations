Explain the difference between a mutex and a semaphore.

Focus on ownership, signaling, and standard use cases in multi-threaded environments.

check_circle Optimal Output

Mutex (Mutual Exclusion): A locking mechanism used to synchronize access to a resource. Only the thread that acquired the mutex can release it (Ownership).

Semaphore: A signaling mechanism. A thread waiting on a semaphore can be signaled by a different thread. It acts as an integer counter.

// Mutex: Strict Ownership std::mutex mtx; mtx.lock(); // Critical section mtx.unlock(); // MUST be same thread // Semaphore: Signaling (C++20) std::counting_semaphore<1> sem(0); // Thread A sem.release(); // Signals // Thread B sem.acquire(); // Waits
